# SalesPulse – Retail Sales Analytics

## Project Overview

SalesPulse is a retail sales analytics application developed using JavaScript and Node.js. It analyzes retail sales data, validates records, calculates sales metrics, and generates business insights.

## Objectives

- Validate retail sales data.
- Calculate total revenue and average order value.
- Identify top-performing products.
- Analyze region-wise sales.
- Generate business insights and recommendations.

## Technologies Used

- JavaScript
- Node.js
- CSV Parser
- Visual Studio Code
- Git and GitHub

## Project Modules

1. CSV Data Reading
2. Data Validation
3. Revenue Analysis
4. Product Analysis
5. Regional Analysis
6. Business Insights and Recommendations

## Key Metrics

- Total Revenue
- Total Valid Orders
- Average Order Value
- Total Quantity Sold
- Estimated Gross Profit

## How to Run

1. Install Node.js.
2. Open the project folder in VS Code.
3. Install dependencies using npm install.
4. Run the application using node src/main.js.

## Expected Outcome

The application provides sales performance, data quality results, product analysis, regional analysis, and business recommendations.
